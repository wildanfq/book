# Membangun Server Git dengan Forgejo

## 1. Persiapan Sistem, Pengguna, dan Struktur Direktori

Instalasi native memerlukan pengguna sistem khusus yang terisolasi untuk mengelola repositori Git dan proses latar belakang. Kita akan membuat pengguna sistem bernama `git`, lalu membangun struktur direktori absolut untuk menyimpan konfigurasi, data kerja, log, serta biner Forgejo dengan hak akses yang ketat.

Jalankan perintah berikut:

```bash
sudo apt update
sudo apt install -y git curl

# Membuat pengguna sistem 'git' dengan direktori home di /home/git
sudo adduser --system --group --disabled-password --shell /bin/bash --home /home/git git

# Membuat struktur direktori kerja Forgejo
sudo mkdir -p /var/lib/forgejo /etc/forgejo /var/log/forgejo
```

Atur kepemilikan dan hak akses direktori agar hanya pengguna `git` yang dapat mengaksesnya secara penuh:

```bash
sudo chown -R git:git /var/lib/forgejo /etc/forgejo /var/log/forgejo
sudo chmod -R 750 /var/lib/forgejo /var/log/forgejo
sudo chmod 750 /etc/forgejo
```

## 2. Unduh Biner Forgejo dan Konfigurasi Layanan Systemd

Unduh file biner resmi Forgejo untuk arsitektur Linux AMD64. Contoh di bawah menggunakan versi `v10.0.1`. Anda dapat memeriksa rilis terbaru di:  
https://codeberg.org/forgejo/forgejo/releases

```bash
# Unduh biner resmi Forgejo
curl -fLo /tmp/forgejo-10.0.1-linux-amd64 \
  https://codeberg.org/forgejo/forgejo/releases/download/v10.0.1/forgejo-10.0.1-linux-amd64

# Pindahkan ke direktori eksekusi standar dan beri izin eksekusi
sudo mv /tmp/forgejo-10.0.1-linux-amd64 /usr/local/bin/forgejo
sudo chmod 755 /usr/local/bin/forgejo
```

Agar Forgejo berjalan otomatis saat server dinyalakan, buat berkas layanan systemd:

```bash
sudo nano /etc/systemd/system/forgejo.service
```

Isi berkas tersebut dengan konfigurasi berikut:

```ini
[Unit]
Description=Forgejo (Beyond coding. We forge.)
After=network.target

[Service]
Type=simple
User=git
Group=git
WorkingDirectory=/var/lib/forgejo/
RuntimeDirectory=forgejo
Environment=USER=git HOME=/home/git FORGEJO_WORK_DIR=/var/lib/forgejo
ExecStart=/usr/local/bin/forgejo web --config /etc/forgejo/app.ini
Restart=always
RestartSec=2s

[Install]
WantedBy=multi-user.target
```

Simpan berkas tersebut, lalu muat ulang daemon systemd dan aktifkan layanannya:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now forgejo
sudo systemctl status forgejo --no-pager
```

Jika layanan gagal berjalan, periksa log dengan perintah:

```bash
sudo journalctl -u forgejo -n 50 --no-pager
```

## 3. Inisialisasi Web dan Konfigurasi `app.ini`

Buka peramban dan akses dasbor instalasi melalui IP server Anda:

```
http://10.64.142.206:3000
```

Pada halaman pengaturan instalasi web pertama, isi parameter berikut secara presisi:

1. **Database Type**: Pilih **SQLite3** — paling ringan dan cocok untuk server kecil.  
2. **Path**: Isi dengan `/var/lib/forgejo/data/forgejo.db`  
   Direktori ini berada di dalam direktori kerja milik pengguna `git`.  
3. **Repository Root Path**: Isi dengan `/var/lib/forgejo/data/forgejo-repositories`  
4. **Server Domain**: Masukkan alamat IP server Anda, misalnya `10.64.142.206`  
5. **SSH Port**: Masukkan `222`  
   Karena Forgejo dipasang secara native, port `222` akan didengarkan oleh server SSH bawaan Forgejo. Ini menghindari bentrok dengan SSH sistem yang biasanya menggunakan port `22`.  
6. **HTTP Listen Port**: Biarkan tetap `3000`  
7. **Base URL**: Ubah menjadi `http://10.64.142.206:3000`

Lengkapi pembuatan akun administrator pada formulir paling bawah, lalu klik **Install Forgejo**. Sistem akan otomatis membuat berkas konfigurasi produksi di `/etc/forgejo/app.ini`.

Setelah instalasi web selesai, restart layanan agar konfigurasi baru dibaca ulang dan amankan berkas konfigurasi:

```bash
sudo systemctl restart forgejo
sudo chmod 600 /etc/forgejo/app.ini
sudo systemctl status forgejo --no-pager
```

## 4. Autentikasi SSH dan Unggahan Perdana

Agar operasi Git melalui port non-standar `222` berjalan lancar, buat pasangan kunci SSH di komputer lokal Anda, lalu salin kunci publiknya.

Jalankan di laptop/komputer kerja Anda:

```bash
ssh-keygen -t ed25519
cat ~/.ssh/id_ed25519.pub
```

Langkah selanjutnya:

1. Masuk ke antarmuka web Forgejo menggunakan akun admin Anda.  
2. Buka **Settings > SSH / GPG Keys**, klik **Add Key**, lalu tempel kunci publik yang sudah disalin.  
3. Uji koneksi SSH dari terminal lokal Anda:

```bash
ssh -T -p 222 git@10.64.142.206
```

Saat pertama kali menghubungkan, Anda mungkin diminta konfirmasi host key. Ketik `yes` lalu tekan Enter. Jika berhasil, akan muncul pesan seperti:

```
Hi there, <username>! You've successfully authenticated...
```

Buat repositori kosong baru bernama `backend` melalui antarmuka web Forgejo. Setelah itu, dari komputer lokal Anda, lakukan inisialisasi dan unggah repositori perdana:

```bash
mkdir first && cd first
git init
touch README.md
git checkout -b main
git add README.md
git commit -m "first commit"

# Daftarkan remote URL menggunakan format port eksplisit 222
git remote add origin ssh://git@10.64.142.206:222/<username>/backend.git

git push -u origin main
```

> **Catatan:** Ganti `<username>` dengan nama pengguna akun Forgejo Anda.

## 5. Prosedur Pembaruan (Upgrade) Versi Native

Keuntungan instalasi native adalah proses pembaruan yang cepat. Anda hanya perlu mengganti file biner lama dengan biner versi terbaru. Konfigurasi di `/etc/forgejo/app.ini` dan database SQLite di `/var/lib/forgejo/data/` tetap aman.

Sangat disarankan untuk mem-backup konfigurasi dan data sebelum melakukan pembaruan.

```bash
# Hentikan layanan Forgejo agar database tidak berubah selama backup
sudo systemctl stop forgejo

# Backup konfigurasi dan data
sudo mkdir -p /var/backups
sudo cp /etc/forgejo/app.ini /etc/forgejo/app.ini.bak
sudo tar -czf /var/backups/forgejo-data-$(date +%F).tar.gz -C /var/lib/forgejo data

# Unduh biner versi terbaru, contoh v10.0.2
curl -fLo /tmp/forgejo-10.0.2-linux-amd64 \
  https://codeberg.org/forgejo/forgejo/releases/download/v10.0.2/forgejo-10.0.2-linux-amd64

# Gantikan biner lama dengan yang baru
sudo mv /usr/local/bin/forgejo /usr/local/bin/forgejo.old
sudo mv /tmp/forgejo-10.0.2-linux-amd64 /usr/local/bin/forgejo
sudo chmod 755 /usr/local/bin/forgejo

# Jalankan kembali layanan
sudo systemctl start forgejo

# Pastikan layanan berjalan normal pada versi baru
sudo systemctl status forgejo --no-pager
```

Untuk memastikan versi biner yang sekarang terpasang, jalankan:

```bash
sudo -u git /usr/local/bin/forgejo --version
```

Jika terjadi masalah setelah pembaruan, Anda dapat mengembalikan biner lama dengan:

```bash
sudo mv /usr/local/bin/forgejo.old /usr/local/bin/forgejo
sudo systemctl restart forgejo
```
