# Server Git

Membangun server Git menggunakan **Forgejo**, layanan *open source* ringan alternatif GitHub/GitLab CE. Lingkungan yang digunakan: mesin virtual Ubuntu Multipass 26.04 LTS (2 CPU, memori 2 GiB) dengan Podman Engine 5.7.0 (API 5.7.0, Go 1.25.0, linux/amd64).

> **Peringatan:** Konfigurasi ini disederhanakan untuk keperluan belajar. Enkripsi HTTPS dan pencadangan sengaja diabaikan agar proses instalasi tetap mudah diikuti.

## 1. Folder Sistem

Podman Quadlet membaca konfigurasi deklaratif dari direktori `/etc/containers/systemd`. Buat folder dengan:

```bash
sudo mkdir -p /etc/containers/systemd
```

## 2. Jaringan dan Volume Data

Server Git memerlukan jaringan internal terisolasi dan penyimpanan persisten agar data tidak hilang saat kontainer dihidupkan ulang.

definisi jaringan:

```bash
sudo nano /etc/containers/systemd/forgejo.network
```

Isi:

```ini
[Network]
NetworkName=forgejo
```

berkas volume:

```bash
sudo nano /etc/containers/systemd/forgejo-data.volume
```

Isi:

```ini
[Volume]
VolumeName=forgejo-data
```

---

## 3. Kontainer Forgejo

Kontainer akan membuka port `3000` untuk antarmuka web dan port `222` untuk Git melalui SSH. Port `222` dipilih agar tidak bertabrakan dengan SSH bawaan mesin virtual.

konfigurasi kontainer:

```bash
sudo nano /etc/containers/systemd/forgejo.container
```

Salin konfigurasi:

```ini
[Container]
ContainerName=forgejo
Image=codeberg.org/forgejo/forgejo:14
Environment=USER_UID=1000
Environment=USER_GID=1000
Network=forgejo.network
PublishPort=3000:3000
PublishPort=222:22
Volume=forgejo-data:/data

[Service]
Restart=always

[Install]
WantedBy=multi-user.target
```

## 4. Menjalankan Layanan

Muat ulang konfigurasi systemd dan nyalakan layanan `forgejo`. Podman akan otomatis mengunduh *image*, menghubungkan jaringan dan volume, lalu menjalankan kontainer.

```bash
sudo systemctl daemon-reload
sudo systemctl start forgejo
```

Layanan kini berjalan di latar belakang. Anda dapat memeriksa statusnya dengan `systemctl status forgejo`.

## 5. Pengaturan Awal

Buka peramban di komputer lokal dan akses `http://10.64.142.206:3000`. Halaman instalasi Forgejo akan muncul. Isi formulir sebagai berikut:

- **Database Type:** `SQLite3` (paling ringan untuk server kecil).
- **Server Domain:** `10.64.142.206`.
- **SSH Port:** `222`.
- **Administrator Account:** tentukan *username*, kata sandi, dan alamat surel. (Contoh: *username* `wildanfq`.)

Klik **Install Forgejo**, tunggu beberapa detik, lalu masuk menggunakan akun administrator yang baru dibuat.

## 6. Koneksi Komputer Lokal via SSH

Agar dapat mengunggah kode tanpa terus-menerus memasukkan kata sandi, daftarkan kunci publik SSH komputer lokal ke Forgejo.

Di terminal lokal, buat kunci ED25519 (lewati jika sudah ada) dan tampilkan kunci publiknya:

```bash
ssh-keygen -t ed25519
cat ~/.ssh/id_ed25519.pub
```

Salin seluruh isi yang muncul (dimulai dari `ssh-ed25519`). Di antarmuka web Forgejo, buka **Settings > SSH / GPG Keys**, tambahkan kunci baru dengan nama pengenal (misal “laptop”), tempelkan kunci publik, lalu simpan.

Uji koneksi dengan perintah ini (ketik `yes` jika diminta konfirmasi):

```bash
ssh -T git@10.64.142.206 -p 222
```

Pesan balasan akan menampilkan nama pengguna Anda, menandakan koneksi berhasil.

## 7. Unggah Proyek Pertama

Buat repositori kosong melalui antarmuka web Forgejo, misalnya bernama `backend`. Catat URL SSH yang ditampilkan, yaitu `ssh://git@10.64.142.206:222/<username>/backend.git` (ganti `<username>` dengan nama administrator yang Anda buat, contoh `wildanfq`).

Di terminal lokal, jalankan perintah berikut secara berurutan:

```bash
mkdir first
cd first
git init
touch README.md
git checkout -b main
git add README.md
git commit -m "first commit"
git remote add origin ssh://git@10.64.142.206:222/wildanfq/backend.git
git push -u origin main
```

Setelah *push* berhasil, segarkan halaman repositori—berkas `README.md` kini tersimpan di server.

## 8. Memperbarui Versi Forgejo

Saat versi baru tersedia (misal dari `14` ke `15`), pembaruan cukup dilakukan dengan mengubah *image* dan memulai ulang kontainer. Data repositori tidak akan tersentuh.

Edit berkas kontainer:

```bash
sudo nano /etc/containers/systemd/forgejo.container
```

Ubah baris:

```
Image=codeberg.org/forgejo/forgejo:14
```

menjadi:

```
Image=codeberg.org/forgejo/forgejo:15
```

Simpan, lalu jalankan:

```bash
sudo systemctl daemon-reload
sudo podman pull codeberg.org/forgejo/forgejo:15
sudo systemctl restart forgejo
```

Forgejo akan berhenti sejenak, mengunduh versi baru, menjalankan migrasi basis data otomatis, lalu kembali menyala dengan versi terbaru.
