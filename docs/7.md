# Instalasi Webmin

Webmin adalah antarmuka administrasi sistem berbasis web untuk server mirip Unix. Dengan Webmin, Anda dapat mengelola konfigurasi internal sistem seperti user, disk quota, layanan, file konfigurasi, serta berbagai aplikasi open-source melalui browser.

---

## 1. Spesifikasi Server

Praktik ini menggunakan VM Multipass bernama `Backrest` dengan OS Ubuntu 26.04 LTS.

| Informasi   | Nilai            |
|-------------|------------------|
| Hostname    | Backrest         |
| OS          | Ubuntu 26.04 LTS |
| Codename    | resolute         |
| Username    | ubuntu           |
| IP Address  | 10.64.142.167    |
| Webmin Port | 10000            |

---

## 2. Masuk ke Server

Masuk ke VM Multipass dari komputer host:

```bash
multipass shell Backrest
```

---

## 3. Perbarui Repository Ubuntu

```bash
sudo apt update
```

---

## 4. Tambahkan Repository Resmi Webmin

Gunakan script resmi Webmin untuk menambahkan repository dan GPG key pada sistem Debian/Ubuntu.

```bash
curl -o webmin-setup-repo.sh https://raw.githubusercontent.com/webmin/webmin/master/webmin-setup-repo.sh
sudo sh webmin-setup-repo.sh
```

---

## 5. Install Webmin

```bash
sudo apt-get install webmin --install-recommends
```

Jika ada konfirmasi, ketik `Y` lalu tekan Enter.

---

## 6. Verifikasi Webmin Berjalan

Cek status layanan:

```bash
sudo systemctl status webmin
```

Atau cek port default Webmin (TCP 10000):

```bash
sudo ss -lntp | grep 10000
```

---

## 7. Akses Webmin dari Browser

Buka browser pada laptop yang dapat mengakses server, lalu kunjungi:

```text
https://10.64.142.167:10000
```

Peringatan "Not Secure" mungkin muncul karena Webmin menggunakan sertifikat HTTPS yang belum dipercaya browser. Anda dapat melanjutkan untuk keperluan praktik.

---

## 8. Login ke Webmin

Webmin menggunakan autentikasi Unix. Login dengan user sistem yang memiliki hak sudo (misalnya `ubuntu` beserta password-nya). Jika ingin mengatur atau mengubah password Webmin khusus, gunakan:

```bash
sudo webmin passwd username
```

---

## 9. Fitur Setelah Login

Setelah login, Webmin menyediakan modul untuk mengelola user, service, filesystem, package, jaringan, serta layanan seperti SSH, Apache, database, DNS, Samba, dan lain-lain. Tersedia juga **File Manager** dan **Terminal** berbasis browser.

---

## 10. Keamanan Dasar

Webmin memberikan akses administrasi penuh; jangan membuka port 10000 ke internet tanpa perlindungan tambahan (misalnya firewall atau VPN). Untuk lingkungan lokal/praktik, cukup gunakan melalui jaringan host seperti saat ini.

---

## 11. Pembaruan Webmin

Karena terpasang melalui repository resmi, Webmin dapat diperbarui dengan perintah APT biasa:

```bash
sudo apt update
sudo apt upgrade webmin
```
