# Instalasi Webmin di Ubuntu

Webmin adalah antarmuka administrasi sistem berbasis web yang memungkinkan pengelolaan server Unix melalui browser. Panduan ini mencakup instalasi, verifikasi, dan akses awal Webmin pada Ubuntu.

---

## 1. Perbarui Repository

Segarkan indeks paket sistem agar mengenali dependensi terbaru.

```bash
sudo apt update
```

## 2. Tambahkan Repository Webmin

Repository default Ubuntu sering tidak menyediakan versi Webmin terbaru. Tambahkan repository resmi dari pengembang dengan skrip berikut:

```bash
curl -o webmin-setup-repo.sh https://raw.githubusercontent.com/webmin/webmin/master/webmin-setup-repo.sh
sudo sh webmin-setup-repo.sh
```

## 3. Instal Webmin

Pasang paket Webmin beserta rekomendasi modul pendukungnya.

```bash
sudo apt-get install webmin --install-recommends
```

Setujui konfirmasi dengan mengetik `Y` jika diperlukan.

## 4. Verifikasi Layanan

Pastikan Webmin berjalan dengan memeriksa status layanan:

```bash
sudo systemctl status webmin
```

dan pastikan port default TCP 10000 terbuka:

```bash
sudo ss -lntp | grep 10000
```

## 5. Akses dari Browser

Buka browser dan kunjungi alamat server Anda dengan protokol HTTPS pada port 10000, misalnya:

```text
https://10.64.142.167:10000
```

Peringatan keamanan akan muncul karena sertifikat self-signed; abaikan untuk keperluan praktik.

## 6. Login

Masuk menggunakan akun pengguna sistem yang memiliki hak sudo (misalnya `ubuntu` dan kata sandinya). Untuk mengatur kata sandi khusus Webmin, gunakan:

```bash
sudo webmin-passwd nama_pengguna
```

## 7. Pembaruan

Karena Webmin terpasang melalui repository APT, perbarui secara berkala dengan:

```bash
sudo apt update && sudo apt upgrade webmin
```

---

> Jangan biarkan port 10000 terbuka ke internet tanpa perlindungan firewall atau VPN. Untuk lingkungan lokal, akses melalui jaringan internal sudah cukup. Selalu gunakan kata sandi yang kuat.
