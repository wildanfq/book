# Object Storage S3 dengan RustFS

## 1. Persiapan Sistem dan Instalasi RustFS

RustFS adalah penyimpanan objek (*object storage*) berkinerja tinggi yang kompatibel dengan protokol Amazon S3 API. Instalasi dilakukan melalui skrip resmi yang akan mengunduh biner, menyiapkan direktori penyimpanan data, serta mendaftarkan layanan ke dalam sistem manajemen Linux.

Pastikan paket yang diperlukan tersedia, lalu jalankan skrip instalasi dengan hak akses root.

```bash
sudo apt update
sudo apt install -y unzip curl openssl

# Unduh skrip instalasi resmi RustFS
curl -fLo /tmp/install_rustfs.sh https://rustfs.com/install_rustfs.sh

# Jalankan skrip instalasi dengan sudo
sudo bash /tmp/install_rustfs.sh
```

Setelah instalasi selesai, pastikan layanan RustFS berjalan dan terdaftar untuk aktif otomatis saat server dinyalakan:

```bash
sudo systemctl enable --now rustfs
sudo systemctl status rustfs --no-pager
```

Jika layanan belum berjalan, periksa log dengan:

```bash
sudo journalctl -u rustfs -n 50 --no-pager
```

## 2. Konfigurasi Kredensial dan Layanan Systemd

Secara bawaan, skrip menempatkan berkas konfigurasi di `/etc/default/rustfs` dengan kredensial yang tidak aman. Anda harus segera mengganti kredensial tersebut dengan kunci akses dan kunci rahasia yang kuat.

1. Membuat Kunci Akses dan Kunci Rahasia

Gunakan OpenSSL untuk membuat kunci secara acak.

```bash
# Membuat Access Key (20 karakter heksadesimal huruf besar)
ACCESS_KEY=$(openssl rand -hex 10 | tr 'a-f' 'A-F')
echo "Access Key: $ACCESS_KEY"

# Membuat Secret Key (40 karakter acak tanpa karakter yang menyulitkan)
SECRET_KEY=$(openssl rand -base64 32 | tr -d '/+=' | head -c 40)
echo "Secret Key: $SECRET_KEY"
```

> **Mengapa format seperti ini?**  
> Access Key sebaiknya berupa alfanumerik huruf besar agar kompatibel dengan standar AWS Signature Version 4. Secret Key boleh lebih panjang dan kompleks, tetapi hindari karakter `/`, `+`, dan `=` untuk mencegah masalah pada penguraian konfigurasi atau klien S3.

Simpan kedua nilai tersebut di tempat aman, misalnya di password manager.

2. Mengedit Berkas Konfigurasi

Buka berkas konfigurasi utama:

```bash
sudo nano /etc/default/rustfs
```

Sesuaikan parameter kredensial menjadi seperti berikut:

```
RUSTFS_ACCESS_KEY=ABCDEF1234567890ABCD
RUSTFS_SECRET_KEY=YourSecretKeyHere
```

Ganti nilai di atas dengan Access Key dan Secret Key yang telah Anda buat.

Simpan berkas, lalu muat ulang manajer sistem dan restart layanan RustFS:

```bash
sudo systemctl daemon-reload
sudo systemctl restart rustfs
sudo systemctl status rustfs --no-pager
```

Layanan RustFS akan berjalan di latar belakang dan mendengarkan pada:

- **Port 9000** – API S3
- **Port 9001** – Konsol Web manajemen

Anda dapat memverifikasi port yang terbuka dengan:

```bash
ss -tulpn | grep -E '9000|9001'
```

Jika firewall aktif, izinkan akses ke kedua port tersebut:

```bash
sudo ufw allow 9000/tcp
sudo ufw allow 9001/tcp
sudo ufw reload
```

## 3. Inisialisasi Dasbor Web dan Pembuatan Bucket

Akses dasbor manajemen RustFS melalui peramban dengan URL:

```
http://<ip-server>:9001
```

Masuk menggunakan kredensial yang telah Anda atur pada langkah sebelumnya:

- **Access Key**: `RUSTFS_ACCESS_KEY`
- **Secret Key**: `RUSTFS_SECRET_KEY`

Setelah berhasil masuk, lakukan inisialisasi kontainer logis (*bucket*) untuk menampung data objek.

1. Pada halaman utama Konsol, klik tombol **Create Bucket**.
2. Masukkan nama bucket yang unik dan permanen, contoh: `rustfs-backup-storage`.
3. Konfirmasikan pembuatan, lalu buka bucket tersebut untuk memastikan ruang penyimpanan siap menerima unggahan file.

Anda dapat mengunggah file langsung melalui antarmuka web dengan masuk ke bucket, lalu menggunakan tombol upload.
